# 工作台第一轮优化

2026-11-16。本轮覆盖按需加载、空闲轮询和提示词优化的用量及错误反馈；不涉及聊天虚拟化、编排器重构或桌面发布。

## 按需加载

命令面板、快捷键、技能管理、运行评测、Agent 模板、手机访问、媒体模型和官方账号设置改为动态导入。各面板使用独立的加载与错误边界，下载失败不会卸载聊天区。加载中的弹窗可以关闭；加载失败时提示保留草稿后刷新重试。

官方账号和媒体模型设置在第一次访问对应分类时加载；同一次设置窗口内切换分类后保持挂载，避免丢失授权进度或表单状态。终端保留原有按需加载方式。

同一依赖环境，以 `38b28aa` 的 Web 源码为基线构建，桌面入口 JS 从 645,707 字节降至约 549 KB，减少约 15%。这仅比较入口分块，不代表所有 JavaScript 的总体积，也不是实际启动耗时。最终构建和对比记录位于 `test-results/optimization-build-final.log`、`test-results/workbench-bundle-comparison.json`。入口仍超过 500 kB，保留构建告警。

## 轮询

- 子任务：会话或子任务活跃时每 1.5 秒，空闲时每 30 秒。
- 目标：活跃时每 1.5 秒，空闲时每 30 秒，作为状态事件的补偿。
- 自动任务：存在启用计划时每 10 秒，否则每 60 秒。
- 页面隐藏时暂停上述定时请求，重新可见时立即刷新。间隔从上一次请求结束后计算，慢请求不会堆积。
- 同资源、同导航版本的自动和手动查询合并；切换项目或会话后丢弃旧导航响应。目标查询同时检查修改版本。

任务执行和 WebSocket 实时事件不随页面隐藏暂停。其他客户端修改空闲任务后的发现速度受补偿轮询间隔影响，返回页面会立即刷新。

## 提示词优化

SQLite 新增独立辅助用量表，按请求编号去重，保存工作区、用途、模型、时间和用量，不保存提示词正文。统计合并到对应工作区和全部工作区的总量及日期区间，单独展示辅助累计，不增加聊天轮次。已收到用量但改写无效、截断或取消的调用也计入；未收到的服务商用量无法补全。

用量写入后通过鉴权 WebSocket 通知有权访问的客户端使缓存失效。新增错误分类供前端本地翻译，区分认证、模型配置、限流、超时、格式和连接问题；不直接展示服务商原始错误。详见[提示词优化](prompt-optimization.md)。

- `npm run check`：源码、前端、E2E、12 个工作区测试类型检查及 8 套主题对比度通过；后续增加的面板错误边界和 E2E 修改又通过对应前端与 E2E 类型检查。
- 7 个文件、48 项定向测试通过：轮询生命周期、请求合并、用量去重与持久化、跨工作区权限、日期统计、错误分类，以及真实 Pi ModelRuntime 连接本机模拟服务的用量回传。
- 17 项相关浏览器用例最终通过：提示词优化 3 项、用量总览 2 项、运行评测 1 项、新增工作台加载与轮询 4 项、媒体设置 1 项、项目切换 4 项、技能管理 2 项。覆盖桌面与 390px 布局、草稿保留和模块加载失败后的隔离。
- 修正评测测试“点击新对话立即创建会话”的旧前置条件，保留创建数量和业务断言；测试临时根目录解析为真实路径，避免 macOS `/var` 别名触发技能目录符号链接检查，未放宽产品安全规则。
- 生产构建通过。改动文件 lint 无错误，保留既有未使用导入和控制字符正则警告。桌面用量与错误提示通过 ego-browser 视觉检查，手机用量检查使用本轮 E2E 截图。错误提示首次截图因开发服务器热更新超时，重新观察页面后再次截图并检查成功。
