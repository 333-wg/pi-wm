# 手机访问与对话工作台

在电脑上运行 Pi-Wm，从手机浏览器查看并继续**同一个会话**，也可经电脑明确授权后在已有项目中新建任务。Agent、文件和工具仍在电脑执行，不是远程桌面，也不需要手机安装模型运行时。

## 使用方法

1. 构建并启动当前版本（源码开发先 `npm run build`，然后 `npm run desktop` 或 `npm run local`）。
2. 打开 **设置 → 手机访问**。默认关闭，每次应用启动都需要手动开启；保存的连接参数不会自动启动隧道。
3. 选择连接方式，阅读授权说明并开启。
4. 生成配对二维码，用手机常用浏览器打开；填写设备名称并请求配对。
5. 回到电脑设置确认设备。需要新建会话、重命名/归档、选择模型/技能及上传附件时，明确勾选「允许完整对话能力」；不勾选仍为基础接续。旧设备不会因升级自动扩大权限，需重新配对授权。二维码有效期 5 分钟、一次性使用；设备授权默认 30 天。
6. 手机选择项目和会话，发消息、查看结果、停止任务或处理普通工具审批。完整对话授权可从左上角项目树点击「新对话」直接创建并进入会话；底部模型标签打开「模型与思考」，在输入框输入 `/` 可筛选并选择电脑已安装的技能，输入框左下角「＋」上传附件。右上角「⋯」提供会话管理与显示偏好。

源码更新后须在合适时间重启本地服务才能加载新增后端；本轮开发不会替你重启已连通的真实入口。重启后入口默认关闭，临时域名可能变化，需重新开启并配对。

电脑必须开机、联网、未休眠且 Pi-Wm 正在运行。Windows 桌面窗口关闭后进入已有托盘模式；从托盘退出或系统休眠会停止访问。手机切后台、锁屏或刷新不会主动取消电脑任务。

## 再次访问与浏览器授权

配对成功后，在**同一个普通浏览器**收藏不带 `#pair` 的 `/phone` 地址。只关闭标签页不会撤销设备授权；同一域名下再次打开会通过安全 Cookie 自动检查授权，不需要重复使用一次性二维码。从其他网站点击链接允许进入公开页面，但 API、附件和 WebSocket 仍执行同源和设备授权检查。

扫码工具内置浏览器、聊天软件浏览器与系统浏览器通常不共享 Cookie；更换浏览器、无痕会话结束、清除站点数据、主动退出授权、过期或撤销后，仍需新二维码配对。Cloudflare 临时域名变化后旧收藏无法跳到新域名，也不会跨域转移凭据。建议第一次就用日常浏览器配对。

入口页区分检查中、扫码配对、等待电脑确认和无授权状态，提供「重新检查授权」、不含凭据的入口复制和常见原因说明。暂时断网不会被直接当作授权失效。手机与桌面按入口拆分加载；内容哈希命名的构建静态资源可缓存，入口 HTML、授权接口和用户附件保持 `no-store`。这减少客户端资源开销，不保证 Cloudflare 或移动网络本身的延迟。

## 连接方式

### Cloudflare 临时 HTTPS 隧道

自行安装官方 `cloudflared`，在设置中填写程序绝对路径（文件名 `cloudflared` 或 `cloudflared.exe`）。本功能不会自动下载、不读取或配置 Cloudflare 账号、不购买服务。

开启后启动独立子进程，仅转发新建的手机回环端口。使用隔离的空配置，避免意外继承用户已有 tunnel 配置。连接就绪后显示临时 HTTPS 地址；连续失败最多退避重试 3 次。单轮启动最多等待 20 秒（包括申请地址与边缘连接），连续失败后的退避为 2、4、8 秒。取得临时地址后，边缘连接失败时依次切换 HTTP/2（TCP 7844、自动 IP）、QUIC（UDP 7844、自动 IP）、HTTP/2（IPv4）、QUIC（IPv4）；取得地址至少 5 秒后，若累计出现至少两次、间隔至少 1 秒的传输失败日志，会提前结束本轮并切换，单次错误和同一批重复日志不会立即触发切换。尚未分配地址时只有限重试入口申请，不切换无关的边缘协议。连接成功后重置连续失败计数，后续子进程断开从下一策略开始恢复；就绪后的日志不会触发上述启动超时或提前切换。程序路径/执行权限错误或不支持的参数不作网络重试，不支持的参数会立即终止启动。设置显示当前协议/IP 策略、已尝试次数、下次重试倒计时及脱敏错误分类；仅分配域名不算连接就绪。DNS 或边缘连接错误是排查线索，不足以单独认定 Clash/防火墙为根因。关闭手机访问会停止该子进程并取消连接超时和重试。

**Clash / VPN 兼容边界：** 本功能不修改系统 DNS、代理、TUN、路由或防火墙，不扫描代理端口，不关闭 TLS 校验。协议切换只能改善某一种传输或 IP 路径不可用的情况，不能保证所有代理线路都能连接。临时入口申请需要 `api.trycloudflare.com` 的 HTTPS 连接，边缘隧道需要 TCP/UDP 7844 至少一种可用；普通网页可访问不代表隧道可连接。仅设置系统 HTTP 代理也不保证 cloudflared 的所有连接会经过它。入口申请失败时，切换边缘协议不会修复该阶段的 HTTPS 问题。Fake-IP/TUN 引起的路由问题仍需用户在代理软件中检查连接记录和规则；应用不会擅自绕过用户网络策略。错误仅保留固定分类，不持久化原始日志、凭据或本地路径。

临时域名可能在重新建立隧道后变化；域名改变会使当前连接关闭，旧域名授权不能用于新域名，需要重新配对。服务商的网络可达性、限额及使用政策需自行确认。标准 HTTPS 隧道不是中转不可读的端到端加密，服务商可能接触会话、指令、文件内容。

### 已有固定 HTTPS 反向代理

填写完整 HTTPS origin（无路径），选择固定本机端口，例如 `5188`。本功能只建立 `127.0.0.1:5188` 上的独立手机服务，**填入域名不等于建立网络通道、配置 DNS 或签发证书**。

代理必须：

- 使用有效 HTTPS 证书。
- 转发 `/phone`、静态 `/assets/*`、`/api/phone/*`、`/api/ws`、受限附件下载 `/api/artifacts/:id` 和上传 `/api/workspaces/:id/artifacts`。上传仍由独立手机入口鉴权。
- 保留公网 `Host` 和浏览器 `Origin`，支持 WebSocket upgrade。
- 上游指向**手机服务端口**，不能指向现有桌面 Gateway。

如果代理和电脑不在同一台机器，需要另行建立受控的反向隧道/VPN 路由。例如电脑向自有服务器建立 SSH 回程，服务器 HTTPS 代理再访问该回程端口。本版不负责 SSH 密钥配置或 SSH 进程管理。

公网地址显示为“已配置”不表示手机可达。首次设置后应关闭手机 Wi-Fi，用蜂窝网络验收；二维码本身不会完成内网穿透。不要为了连通而解除主 Gateway 的回环限制。

## 权限和数据边界

- 手机入口与主 Gateway 分开监听；只绑定回环。没有免认证模式。
- 管理接口仍要求本机连接和管理员凭据；手机 Cookie 不能授权管理接口。
- 配对材料只保存在内存，重启失效；设备凭据只持久化 SHA-256 哈希。连接配置和设备记录位于数据目录 `phone-devices.json`，Windows 继承用户目录 ACL，应避免放入共享目录。
- 手机凭据使用 `__Host-`、Secure、HttpOnly、SameSite=Strict Cookie，不放入 localStorage；域名及设备有效期都参与校验。
- 项目授权冻结为配对时已有的项目集合；后续新增项目需重新配对。撤销单台设备、关闭入口或凭据过期后连接失效。
- 完整对话授权按设备保存；新建会话仅允许已授权项目、电脑已配置且可用的模型，服务端强制 `workspace_write` 和 `on_risk`，不能自行降为无审批。已有会话继续沿用原权限。
- 手机上传最多每文件 10 MB（还受已有附件类型/大小校验限制），每分钟最多 30 次；界面每条消息最多 8 个附件。上传并非任意目录写入，附件引用仍校验工作区。手机附件响应使用 `no-store`。
- WebSocket 指令允许列表与现有工作区鉴权叠加；不开放直接终端、任意文件浏览、模型密钥管理、MCP 管理、修改会话权限等接口。Computer Use 人工审批仍只能在电脑处理。
- **手机发消息仍可驱动 Agent 使用原会话已经授权的工具**，不是只读访问或额外 OS 沙箱。请勿把“没有手机终端按钮”误解成“不能让 Agent 执行命令”。
- 普通审批记录包含手机设备标识；拒绝跨站 Host/Origin 请求，配对、API 和 WebSocket 有限流。
- 首次二维码原料在 URL fragment 中，页面加载后移除；请勿公开二维码或配对链接。

## 手机界面及恢复

手机使用独立导航布局，并复用桌面 Markdown/代码高亮组件：

- 紧凑单层顶栏与项目/会话抽屉，按名称筛选最近 200 个会话，查看归档；聊天正文不再与设置表单争用屏幕。
- 经完整对话授权后可新建、重命名、归档和恢复，切换已有模型及支持的思考强度，选择已安装 Skill。
- Markdown、代码复制、消息复制、图片内联显示、附件上传与下载、可折叠工具结果和思考过程。
- 浅色/深色、标准/大字、隐藏思考或工具过程；显示偏好仅保存在当前浏览器，不修改电脑。
- 独立滚动对话区、轻量用户气泡和无外框 AI 正文；输入框从 48px 自动增高至最多 144px，支持收起且保留草稿。附件条限高滚动，回到底部按钮随输入区高度调整。
- 模型、会话设置在手机上使用底部面板，在宽屏使用居中面板；支持关闭按钮、Esc、背景点击和浏览器返回关闭，关闭后恢复触发按钮焦点。显示偏好改变时尽量保持当前消息阅读位置。
- 可视视口/安全区域适配；真实 iOS/Android 软键盘仍需实机验收。
- 最近项目/会话、草稿、已上传待发送附件与 Skill 选择在本浏览器标签页存储中恢复。

- 技能通过 `/` 候选列表选择，以可移除标签显示并恢复；Team 启动提交成功后自动取消该技能，避免下一条普通消息再次启动团队。
- 电脑执行期间可编辑草稿，但发送需等当前会话空闲；尚未接入即时补充和队列。需要 Computer Use 本地审批时明确提示去电脑确认，不在手机显示无效批准按钮。
- 当前会话有团队启动工具记录时显示只读团队状态卡，每 15 秒在前台同步关联团队，可查看任务进度和最终结果。会话空闲不代表团队完成；团队停止和管理仍需电脑端操作。断线或同步失败时保留上次状态并标明。
- 项目会话与技能列表区分加载、失败和空结果；后台会话阶段事件直接更新项目列表，当前会话快照同步合并请求。

尚不包含消息编辑/Fork、即时补充与队列、完整团队管理面板、文件/Git 浏览、后台推送、PWA 安装或原生 App。这些属于后续批次。

实时连接使用同一 Gateway 协议，重连发送 cursor 并重新获取所选会话快照；持久事件到达时合并拉取权威快照。任务生命周期与浏览器连接分离。草稿在本浏览器 sessionStorage 按会话隔离；发送前保存提交 ID，结果未知不自动重发，相同文本/附件/Skill 组合重试复用原 ID（兼容旧版文本草稿 ID）。新建会话同样保存幂等 ID，相同参数手动重试不会重复创建。重连有退避和手动入口，必须完成协议握手后才能发指令；明确撤销后停止重连。请求限流等待 60 秒后重新连接，不重放指令，也不要求重新配对；其他策略关闭提示检查电脑端后手动重连。浏览器清理存储后无法保证继续复用该 ID，应先核对历史。

```sh
npm run build

```

端到端使用 `apps/gateway/test/phone-preview.mts`：隔离临时目录、真实 Gateway/Orchestrator、本机 HTTPS 代理和演示 Runtime，无真实模型、付费调用、真实工具执行或公网发布。测试上下文仅为此 fixture 接受自签名证书；产品不关闭 TLS 校验。

本机交互预览可运行：

```sh
node --import tsx apps/gateway/test/phone-preview.mts --serve
```

桌面入口 `http://127.0.0.1:5190`，测试口令 `phone-preview-local-only`；控制台打印 HTTPS origin 和回环上游端口。手机 HTTPS fixture 的自签名证书用于自动化测试，不是可部署的证书。
