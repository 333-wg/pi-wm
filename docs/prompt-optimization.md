# 一键优化提示词

桌面端 / Web 工作台输入框的模型选择器左侧新增 ✨「优化提示词」。输入草稿后点击，使用点击时选中的模型、服务商认证和有效思考档位优化文本，完整成功后自动回填原输入框。不会自动发送、创建聊天消息或执行工具。

- 优化期间保留原文，输入框只读、发送及重复优化禁用；可点击「取消优化」。
- 成功后可「撤销优化」恢复原文；继续手动编辑后撤销入口消失，避免覆盖新修改。
- 失败、超时、空返回、截断返回均不回填。切换模型、会话、项目或编辑目标会取消旧请求，并丢弃迟到结果。
- 附件原样保留；优化请求只发送草稿文字，不读取附件、项目文件或会话历史。
- 空输入、`/` 开头的命令、超过 16000 字符的草稿不能优化。
- 每位用户同时最多一个优化请求。接口沿用 Gateway 鉴权、工作区访问和写权限检查，独立手机访问入口暂不开放。
- Demo 运行时不伪造优化结果，返回功能不可用；实际使用需要 Pi 运行时和可用的聊天模型。

## 用量与限制

优化会额外调用模型，可能消耗服务商额度。取消只能尽力中止请求，不能撤销已产生的用量。本版优化请求不进入会话任务，因此尚未纳入应用内会话用量统计，请以服务商账单为准。

优化器的职责是改写提示词，而不是执行原文任务或回答其中的问题。例如「义乌天气」应改写为「请查询义乌的天气情况。」，不应返回天气结果或「无法查询实时天气」的能力声明。优化以保留原意、澄清任务和限制为重点，简单需求保持简洁，不擅自补充时间、功能、技术选型或其他要求。

请求将草稿作为 JSON 中的 `draft` 编辑素材传入，与改写指令区分；系统提示包含天气、代码分析、团队和英文示例。模型必须返回只有 `optimizedPrompt` 字符串字段的 JSON 对象，服务端校验后只将该字段回填。普通回答、空结果、额外字段或错误格式不会覆盖原文，也不会自动重试产生额外调用。

格式校验不等于语义验证：模型仍可能把不合适的回答放入合法字段，或改变原意。优化指令要求保留授权边界、语言、路径和代码，不擅自新增需求，但不能保证所有模型都遵循；发送前仍应检查内容。

## 验证

- 适配层测试：模型/服务商和思考参数、无工具/无历史、草稿隔离及改写结果提取、天气答复/能力声明等非约定格式拒绝、异常结果和取消。
- 本地服务线缆测试：真实 ModelRuntime 向本地 OpenAI-compatible 模拟服务发请求，检查认证、模型及请求内容。
- Gateway 接口测试：鉴权、权限、工作区隔离、输入限制、并发和断连取消。
- Playwright：按钮状态、回填、附件保留、不自动发送、撤销、手动编辑、失败/取消以及切换模型。

这些测试不消耗真实服务商额度，不代表已实测所有第三方服务或官方账号的优化效果。
