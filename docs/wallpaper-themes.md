# 壁纸与氛围主题

入口：**设置 → 常规 → 壁纸与氛围**。

## 当前能力

- 经典外观保留八套配色，默认不启用壁纸。壁纸开启时使用独立协调配色，隐藏经典配色选择；浅色、深色与跟随系统仍生效，关闭壁纸恢复已保存的经典配色。
- 导入图片后在本地以 48 × 48 像素采样主要色系，忽略透明、近黑、近白和低饱和像素，生成浅深两套中性底色与协调强调色。灰度图或采样失败使用中性蓝兜底，不上传图片，不改变已保存的配色偏好。内置渐变使用预设色系。
- 按钮、选中态、文字、边框、代码和终端使用统一的壁纸颜色；错误、警告及语法颜色保留语义，不随壁纸色相改变。
- 内置原创 CSS 渐变「青绿极光」「暮色流光」，可开启缓慢流动；页面不可见时停止动效，遵循系统减少动态效果偏好。
- 「我的壁纸」保存最多 24 张本地图片，展示缩略图、文件名与使用中标记，点击即可切换；添加新图片不覆盖旧图片。每次添加一张 PNG / JPEG / WebP（非空、最大 10 MiB、解码后不超过 4000 万像素），在浏览器中重编码为 WebP，最长边不超过 2560 像素，并生成小尺寸缩略图。
- 默认提供背景强度；水平／垂直焦点、背景遮罩、背景模糊、面板浓度收进高级调整，立即生效并显示预览。背景强度与全屏遮罩透明度直接对应：100% 强度不叠加遮罩，60% 强度使用 40% 遮罩；深浅主题均遵循此规则，预览同步。消息、代码及控件保留局部阅读底色，面板浓度仍是相对材质强度而非最终像素 alpha。已有强度设置不重置，升级后相同设置下的壁纸会更清晰；若文字对比不足，可降低背景强度或提高面板浓度。
- 背景只绘制一次并覆盖全窗（包括桌面标题栏）；侧栏、顶栏、欢迎区不再叠加整块底色。输入框、搜索框、菜单、设置弹层采用分级半透明材质。文件、团队、MCP 等工作视图保持连续背景，消息和代码内容使用局部阅读底色；终端开启透明画布，移动导航使用模糊玻璃层。面板浓度是相对材质强度（不是所有面板的实际 alpha），保留既有参数兼容性。关闭壁纸恢复原有所有配色与终端底色。
- 每张壁纸支持单独删除，卡片内二次确认，可取消。删除当前图片回退「无背景」；删除其他图片不影响当前背景。存储删除失败时保留原图片并提示。
- 「恢复默认背景」只关闭背景并恢复显示参数，不修改经典配色、不清空壁纸库。旧版单张壁纸自动迁入图库（显示为「原有壁纸」），无需重新导入。切换图片时焦点居中，强度、模糊和面板浓度沿用当前设置。

## 存储与安全

图片只保存在当前 origin 的 IndexedDB（`wuming-appearance`），小型配置保存在 `wuming.appearance.background.v1`。不上传、不写入项目目录，也不把图片 Base64 写进 localStorage。同源标签页同步配置与图库增删；不同浏览器、端口和桌面端之间不共享图片。清除站点数据会清除背景。

不支持 SVG、远程 URL、主题脚本、任意 CSS 或 ZIP 包导入。损坏文件、存储失败会显示提示；读取不到图片时回退原有界面。请仅导入有权使用的图片。

此版借鉴 Codex Dream Skin 的连续背景与阅读场景分层思路，未复制其代码、素材或 CDP 注入方式，未新增渲染依赖。

## 当前边界

不包含视频／粒子／3D 壁纸、独立的每图参数收藏、主题包或在线市场。取色是有界的主色系估计，不是人工设计；任意图片的局部文字对比度不能只凭 token 对比测试保证，可用背景强度及高级调整改善。浏览器隐藏页暂停不能替代所有平台上的最小化／遮挡性能验收；Electron 安装包及 macOS 实机仍需独立验证。
