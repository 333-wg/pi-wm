# Pi-Wm v0.1.8

## 本次更新

- 用量统计默认汇总全部工作区，支持单工作区筛选；本地模式保留隐藏、移除项目的历史用量，服务端模式仍按授权工作区隔离。
- 连续普通工具调用按类别汇总并默认折叠，保留助手进度文字、异常、审批、产物和网页证据；展开后仍可查看原始参数和输出。
- 全权限会话自动授权技能与 MCP 管理；始终询问、敏感技能源码和混合能力请求的原有约束保留。
- 清理安装包中的开发源码和非目标原生模块，提高 Windows/macOS 压缩强度。
- Windows 安装后逐项检查运行时文件清单；长 TEMP 路径导致临时解压不完整时直接重新解压到安装目录并再次验证，失败则不启动应用。

## 为什么仍然较大

Windows v0.1.8 解压后约 857.8 MB，v0.1.7 为 917.9 MB。本轮减少约 60.1 MB 的落盘内容，但不能把解压后降幅直接当成下载体积降幅。

| 构成                          | v0.1.8 解压体积 | 用途                                      |
| ----------------------------- | --------------: | ----------------------------------------- |
| Electron 桌面运行时及配套资源 |        336.4 MB | 桌面窗口、界面和内嵌预览                  |
| 自动化浏览器及配套工具        |        244.5 MB | 网页自动化、PDF 生成、浏览器工具          |
| 独立 Node                     |         87.0 MB | 网关、SQLite、PTY 和本地工具              |
| 生产运行依赖                  |        182.1 MB | 模型 SDK、代理运行时、PDF、原生图像模块等 |
| 业务代码、界面和桌面入口      |          7.8 MB | 应用本身，不是主要体积来源                |

Electron 与自动化浏览器都包含 Chromium，但用途和运行方式不同，不能简单删除其中一个。复用 Electron 浏览器、按需下载自动化浏览器或依赖系统运行时都属于后续架构方案，会改变离线可用性、首次使用和兼容性；本次没有擅自引入这些变化。

## 清理范围

- SDK 发布包中不用于默认运行的 TypeScript 源码：约 9.1 MB。
- 非当前平台、架构或 Node ABI 的 Sentry profiler 二进制：Windows 约 4.1 MB。
- 仅供网页端使用的 PDF parser 构建：约 3.6 MB，保留 Node 构建、PDF worker 和 WASM。
- Headless Chromium 多余界面语言资源：Windows 约 43.2 MB，保留英文、简体中文和繁体中文；字体、ICU 和网页语言显示能力保留。
- 继续沿用已有的 source map、类型声明、调试符号和非目标 PTY 清理规则。

清理只发生在生成的打包暂存目录。未删除源码依赖目录、用户项目、聊天记录或历史发布包。许可证、运行时引用的 Pi 文档和示例均保留。

## 限制

- Windows 安装包未进行代码签名；macOS 为 ad-hoc 签名，未公证。系统可能提示未知发布者或安全警告。
- 全量旧版 `e2e/wuming.spec.ts` 中仍有使用已经移除的“目标”页签等旧界面断言，不能宣称整套旧 E2E 全绿。本次功能采用定向回归、现有专项测试和真实安装升级门禁验证。
- 自动化模型验收使用隔离的本地模拟端点，不代表完成了付费真实模型质量评估。
