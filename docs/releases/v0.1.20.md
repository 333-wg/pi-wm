# Pi-Wm v0.1.20：用量趋势、文件预览与浏览器交互优化

基于 v0.1.19 整合本地改动，保留手机远程访问、目录附件、团队流程和聊天外观等已有功能。当前为发布候选，跨平台附件核验完成后正式发布。

## 本次更新

- 用量统计采用曲线与渐变面积图，支持悬停、点击和键盘聚焦查看每日 Token、费用、请求次数及轮数；侧栏增加紧凑趋势图。
- 用量卡片显示 Token 单位，构成明细增加百分比，工具统计增加列标题；改善加载失败、空数据和窄屏布局。
- 文件预览增加语法高亮、行号、只读标识、复制及 10–24px 多档字号选择。字号保存在当前设备；保存失败时明确提示，不影响当前调整。
- 补充 `.cts`、`Dockerfile`、`Makefile` 等文件的语言识别；保留原始文本、安全转义、空文件与二进制提示。
- 成功启动预览后只准备地址，不自动打开浏览器或替换当前侧栏。用户点击地球按钮或“打开预览”后显示；关闭后不会被后续工具活动重新弹出。

## 下载与安装

- Windows x64：`Pi-Wm-0.1.20-Setup-x64.exe`；已配置更新源的客户端可在“设置 > 关于与更新”检查更新。
- Windows 更新附件包含同次构建的 `.exe.blockmap` 与 `latest.yml`，更新源为 `333-wg/pi-wm`。
- macOS Apple Silicon / Intel：待原生构建与校验通过后附加对应 DMG、ZIP 和 SHA-256 文件。Mac 需手动替换应用，不提供自动更新。
- 不包含本地会话数据、预览脚本、备份、临时文件或凭据。

## 验证记录

- 整合并格式化后，`npm run check` 通过：源码、前端、E2E 与测试类型检查，以及 8 套主题各 80 对颜色对比检查。
- `npx vitest run apps/web/test/code-block.test.ts apps/web/test/usage-trend.test.ts`：12 项通过，覆盖语言识别、源代码转义、普通对话代码块兼容及趋势图零值、空数据和非法输入。
- `npx playwright test e2e/file-preview.spec.ts e2e/browser-preview.spec.ts e2e/usage-overview.spec.ts --workers=1`：4 项通过，覆盖字号保存与失败提示、复制文本、滚动、高亮、空文件/二进制/截断提示、预览手动打开与关闭、统计范围及重启保留。
- 已检查桌面用量曲线交互、文件预览深浅主题截图及浏览器面板布局；保留现有用量测试的 390px 窄屏截图检查，未发现本轮明显遮挡或横向溢出。预览面板回归使用桌面桥接夹具，不替代原生网页加载专项验收。
- 浏览器诊断未发现未捕获页面异常、失败请求或 HTTP 错误。
- `npm run desktop:dist` 通过：Windows 安装包为 249,592,938 字节，SHA-512、blockmap、更新源和 15,811 个运行时文件清单校验通过。
- `node scripts/verify-desktop.mjs --packaged=release/win-unpacked/Pi-Wm.exe` 通过：移出源码目录后的包内应用启动、鉴权 API/WebSocket、原生终端、渲染器隔离、单实例、项目与主题保留、重开和正常退出。未执行产品安装器。
- 旧的本地预览脚本复用历史测试数据库时出现 revision 冲突；改用新的隔离预览目录后正常启动，不修改用户数据，不将此夹具问题计为产品修复。
- macOS 原生构建、正式附件摘要及公开更新源验证待完成。

## 已知限制与验证范围

- Windows 安装包未配置发布者签名；macOS 使用 ad-hoc 签名，未经 Apple Developer ID 签名和公证，系统可能提示未知发布者或拦截安装。
- 文件预览为只读；字号设置不跨设备同步，清除站点数据会移除设置。
- 按本轮前端改动执行定向验证，未运行全仓库测试、完整 E2E、完整桌面回归、收费模型或真实安装升级矩阵；不将包内启动和附件校验等同于真实升级验收。
- 构建保留桌面主包超过 500 kB、SQLite 实验性及既有依赖弃用提示；本版不宣称已消除这些问题或改善实际模型计费。
