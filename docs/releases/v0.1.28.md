# Pi-Wm v0.1.28：重连停止、技能权限与项目侧栏修复

已于 **2026-11-26 17:45（北京时间）**正式发布并设为 Latest：[GitHub Release](https://github.com/333-wg/pi-wm/releases/tag/v0.1.28)。Windows x64、macOS Apple Silicon 和 Intel Mac 共九个发布附件均已核验。

## 更新内容

- 修复网络不稳定、API 重试或网关重新连接时停止按钮长时间无法再次点击的问题。重连等待有超时，停止完成后刷新会话；延迟送达的停止仅针对原任务，避免误停下一轮。
- 完全访问模式下允许可信文件工具读取和编辑技能源文件；“始终询问”、禁用技能和仅手动调用规则继续生效。
- 技能管理新增“复制到用户全局”，方便跨项目复用并保留项目原件。完全访问不会自动加载其他项目的技能。
- 项目侧栏默认展示 5 条对话，可展开或收起；改为统一滚动，解决列表被遮挡的问题。
- Git 遇到目录所有者不匹配时，分支菜单显示“需信任仓库”，可确认信任当前目录并自动重试。仅添加准确根目录，写入后检查访问是否真正恢复，原始报错折叠展示。
- 基于 v0.1.27，保留模型服务删除弹窗、团队模型分配等已发布功能；未改变依赖版本。

## 下载与安装

- Windows x64：下载 `Pi-Wm-0.1.28-Setup-x64.exe`，或在客户端通过“设置 > 关于与更新”升级。
- macOS Apple Silicon：下载 `Pi-Wm-0.1.28-mac-arm64.dmg`；Intel：下载 `Pi-Wm-0.1.28-mac-x64.dmg`。同时提供 ZIP 与 SHA-256 校验文件；Mac 通过手动替换应用升级。
- 安装包不包含本地会话、项目数据或凭据。
