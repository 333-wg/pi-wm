# Pi-Wm v0.1.26：团队模型分配、工作台与提示词优化升级

发布版本：0.1.26。构建提交：`5b746658e1b7e76e9d87fbbc69f03af8164cc3c8`。

## 更新内容

- 新团队最初只有 Leader，默认继承开启 team 技能或 `/team` 时所选的对话模型，支持用户切换。
- 进入团队时选择「使用对话默认模型」或「自主选择」。统一模式下所有成员跟随 Leader；自主选择模式下，Leader 按任务需要创建成员，用户为新成员分配模型后才开始调用。
- 待启动成员可在画布内逐个配置，也可批量确认。切换模型保留任务、会话和消息，正在执行的轮次结束后生效；配置状态支持重启恢复。
- 重做团队工作台：紧凑依赖画布、阶段导航、缩放和平移、定位执行中、全屏画布，以及独立通信区和底部成员栏。手机端切换流程与通信视图。
- 通信默认提供简洁摘要，支持展开原文、筛选成员及查看任务结果；团队最终交付结果保留独立入口。
- 开启壁纸时，深浅主题均直接透出全局壁纸；Team 页面、卡片和通信区不再额外叠加白色或黑色底板、遮罩或模糊。

- 提示词优化增加清晰的错误分类与本地化反馈；辅助模型用量按工作区与日期统计，已收到的取消／无效改写用量也计入，不增加聊天轮次。
- 命令面板、技能管理和设置等面板按需加载；使用局部加载及错误边界，降低初始加载开销并保留对话草稿。
- 调整空闲轮询：页面隐藏时暂停相关补偿请求，返回后刷新；同资源请求合并，切换项目时丢弃旧响应。
- 优化 Agent 验证策略，优先定向检查与复用有效证据，保留必要验证门槛；增加浏览器调用与验证耗时的可观测指标。

## 发布范围

本版本包含 Agent Teams、壁纸适配、提示词优化、用量统计、工作台加载及验证流程改动。排除本地生成的设计图片、临时文件、测试报告、会话与凭据。版本与锁文件同步为 0.1.26，不更新依赖版本。

## 已知限制与未执行检查

- 原有团队保留原执行方式，新建团队才默认进入模型分配流程。失败成员切换模型后仍需手动重试。
- 历史自由文本不会改写为推测进度；摘要不代替真实交付结果。透明工作区使用全局壁纸与主题设置，高强度复杂壁纸可能降低文字对比度。
- 不调用真实收费模型；验证使用隔离数据库和 Demo／脚本运行时。
- 按改动风险执行定向检查，不重复全仓库测试、完整 E2E、完整桌面回归或真实安装升级矩阵；本次未修改安装器、更新器及依赖版本。常规全仓库 CI 沿用既有发布策略跳过，采用本地定向检查和原生平台候选验收。
- Windows 未配置发布者签名；macOS 使用 ad-hoc 签名，未经 Apple Developer ID 签名与公证，系统可能拦截安装。
