# Pi-Wm v0.1.14

## 本次更新

- 成功完成任务后，将进度文字和工具记录收进“用时…”入口，最终答复和文件、图片、视频产物保持可见；支持手动展开、搜索命中自动展开。未完成、失败或中止的任务不进行整轮折叠。
- 移除消息级“从这里分叉”按钮，保留历史编辑和会话级分叉；隐藏空闲会话状态点，调整子任务图标并补充中断状态显示。
- 缓存统计区分明确零命中与服务商未上报，按已知请求输入计算命中率并展示覆盖率；压缩请求单独统计，演示数据持续标记，不把缺失字段当成零。
- 团队动态状态与固定协作政策分离，稳定工具 schema 的 required 字段顺序，减少无意义的请求前缀变化。
- 压缩后补齐缺失参考快照，不额外触发模型请求；长任务跨日刷新程序拥有的默认日期，不改写用户自定义提示。
- 重试恢复输出后及时隐藏恢复提示，刷新后不重新出现；避免早先失败使最终成功的任务仍被判失败，防止旧请求覆盖运行状态。

## 安装与更新

- Windows x64：`Pi-Wm-0.1.14-Setup-x64.exe`。已配置更新源的客户端可在“设置 > 关于与更新”检查、下载并确认安装。
- Mac Apple Silicon：`Pi-Wm-0.1.14-mac-arm64.dmg`（269.88 MB）；Intel：`Pi-Wm-0.1.14-mac-x64.dmg`（281.22 MB）。ZIP 是另一种分发格式，无需与 DMG 同时下载；Mac 仍需手动替换应用。
- 不覆盖既有正式版本，不发布本地数据库、预览脚本、私钥或测试专用更新元数据。

## 验证边界与限制

- 缓存字段观察与前缀诊断不是服务商计费审计，不保证线上命中率提高；未运行收费模型基准。
- WebSocket、不支持的协议、超出大小上限的 SSE 帧与旧记录可能缺少缓存字段证据，此时保持未知。
- 过程折叠只改变展示，不删除原始记录，不回滚工具产生的文件或外部操作。
- Windows 安装包未签名；macOS 使用 ad-hoc 签名、未经公证，系统可能提示未知发布者或拦截安装。
- 发布后完整公开下载验证尚未通过：本机隔离 Electron 验收窗口意外关闭，独立匿名下载超时；窗口关闭原因尚未确定，不能据此断言为应用缺陷或网络问题。需在稳定环境补验公开更新下载。
- 发布源码冻结后工作区出现的新改动未混入本版，也未随发布文档提交。
