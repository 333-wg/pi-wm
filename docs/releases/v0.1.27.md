# Pi-Wm v0.1.27：模型服务删除弹窗与地址配置体验优化

## 更新内容

- 将删除模型服务的系统原生确认框替换为 Pi-Wm 应用内弹窗，统一视觉层级与交互。
- 删除前清楚展示服务地址、将被删除的模型数量、API Key 影响范围和不可撤销提示。
- 提供「先不删除」、右上角关闭和遮罩取消操作；删除失败时在弹窗内保留错误信息。
- Base URL 输入框不再使用带 `/v1` 的占位示例，并补充说明：可直接填写服务商提供的地址，系统会自动尝试标准路径。
- 更新模型服务删除流程的浏览器回归断言，并同步中英文界面文案。

## 下载与安装

- Windows x64：下载 `Pi-Wm-0.1.27-Setup-x64.exe`，或在已配置更新源的客户端通过「设置 > 关于与更新」升级。
- macOS Apple Silicon：选择 `Pi-Wm-0.1.27-mac-arm64.dmg`；Intel：选择 `Pi-Wm-0.1.27-mac-x64.dmg`。以 Release 实际附件为准，也提供 ZIP 与 SHA-256 校验文件。Mac 手动替换应用，不提供自动更新。
- 发布附件不包含本地会话、项目数据或凭据。
