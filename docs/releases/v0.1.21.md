# Pi-Wm v0.1.21：修复更新安装误报忙碌

修复后台短暂请求与更新检查重叠时，页面误报“有任务正在运行或终端仍打开”、反复阻止安装的问题。

## 本次修复

- 遇到后台请求或自动调度短暂占用时，每隔 100 毫秒重新检查，最多额外等待 1.5 秒；请求结束即可继续更新。
- 真实运行或排队的任务、执行中的目标、未关闭的终端仍会阻止安装；持续请求、状态未知和服务异常不会被绕过。
- 更新页显示所有会话与项目的具体阻塞项及数量，并提供“前往终端”和“重新检查状态”。收起终端面板仍会保留终端进程，需要在终端内部工具栏关闭。
- 安装确认后继续执行服务端最终空闲检查，只有检查通过才停止服务并交给安装器。

## 下载与升级

- Windows x64：下载 `Pi-Wm-0.1.21-Setup-x64.exe`。已配置更新源的用户可通过“设置 > 关于与更新”升级。
- 旧版 0.1.20 及更早版本若仍卡在忙碌提示，请保存工作、结束真实任务和终端、正常退出 Pi-Wm，再运行本版安装包覆盖原安装目录。旧版需先完成这一次升级，之后才能使用修正后的检查逻辑。保留现有会话与项目数据，不必卸载或删除用户目录。
- macOS：Apple Silicon 使用 arm64，Intel 使用 x64；下载本版对应 DMG 或 ZIP，手动替换应用。
