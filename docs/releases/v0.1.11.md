# Pi-Wm v0.1.11

## 本次更新

- 新增独立「定时任务」中心：可按项目和模型配置名称、描述、提示词及日程，支持编辑、启停、立即执行、删除、执行日志和历史对话。支持每日、每周、每月、一次性及固定间隔日程，按指定时区预览下一次运行。
- 定时任务由本地服务调度，同一任务不会重叠执行；错过的计划不补跑，已领取的运行仍参与故障恢复。原有会话自动化保留，并增加编辑、删除和日历日程，不会自动改成独立任务。
- 整轮任务默认不再受固定 20 分钟期限限制；模型请求连续 10 分钟没有流事件时退出该请求并按现有恢复规则处理。工具执行不计入模型静默时间。
- 改进长任务诊断，显示命令、运行时长与最近输出时间；收紧错误详情和命令显示的凭据脱敏，并隔离桌面宿主环境变量与子进程树。
- 「立即引导」可中断当前执行并优先处理新输入；「稍后跟进」等待当前任务结束，按接收顺序执行。

## 安装与更新

- Windows x64：`Pi-Wm-0.1.11-Setup-x64.exe`。应用内可通过「设置 > 关于与更新」检查、下载并确认安装。
- Mac Apple Silicon：`Pi-Wm-0.1.11-mac-arm64.dmg`；Intel：`Pi-Wm-0.1.11-mac-x64.dmg`。Mac 仍需手动替换应用，ZIP 是另一种分发格式。

## 验证边界与限制

- 独立定时任务固定使用完全访问权限，工作项目指定执行目录，但不是文件系统隔离。仅为信任的任务配置提示词；普通聊天的权限设置不受影响。
- 计划只有在本地服务运行、电脑唤醒时触发；错过的时间不补跑。尚不支持自定义五段 Cron、任务级通知或 Git worktree 隔离。
- 模型流静默保护不保证第三方供应商可用；真实渠道的长期稳定性未由模拟测试覆盖。
- Windows 安装包未签名；macOS 为 ad-hoc 签名、未经公证。系统可能提示未知发布者或拦截安装。
