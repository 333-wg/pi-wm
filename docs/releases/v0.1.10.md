# Pi-Wm v0.1.10

## 本次更新

- 自动重试默认由 2 次增加到 5 次，按 1、2、4、8、16 秒退避；完善 HTTP/2 断流、临时不可用和限流的识别，余额不足、鉴权失败及无效请求不自动重试。
- 重试过程使用单个“正在恢复连接”提示，保留次数与技术详情，刷新后恢复展示；隐藏重复中间报错，正确标记未执行的中断工具调用。
- 侧栏显示运行中会话的动态状态，切换会话后仍同步后台任务的运行、重试和结束状态。
- 优化连续工具记录折叠，支持浏览器操作、失败/中止记录和部分纯文本输出；保留交付文件及媒体的独立展示，调整计数、摘要与窄屏排版。
- Windows 应用内更新显示原生安装进度，依次提示检查、替换、安装和文件校验；校验后自动启动新版，启动失败显示诊断提示。兼容旧版静默更新参数。

## 安装与更新

- Windows x64：`Pi-Wm-0.1.10-Setup-x64.exe`。
- Mac Apple Silicon：`Pi-Wm-0.1.10-mac-arm64.dmg`；Intel：`Pi-Wm-0.1.10-mac-x64.dmg`。
- Mac ZIP 是另一种分发格式，无需与 DMG 同时下载。
- 已配置更新源的 Windows 客户端可在“设置 > 关于与更新”中检查、下载并确认重启安装。安装期间请勿重复打开应用。

## 构建与验证

发布前验证结果将在安装包、源码检查及真实升级验收完成后补充。

## 验证边界与限制

- Windows 安装包未进行代码签名；macOS 为 ad-hoc 签名，未公证，系统可能提示安全警告。
- 自动重试限于被识别为可恢复的模型请求故障，不保证上游服务恢复；额度、权限与模型可用性仍由供应商决定。
- Windows 更新进度改动不改变 macOS 的安装流程，也不宣称提供完整安装回滚。
- 原生安装器夹具测试不替代真实安装升级验收，正式发布前分别记录验证结果。
