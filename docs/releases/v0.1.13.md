# Pi-Wm v0.1.13

## 本次更新

- 优化提示缓存的请求前缀稳定性：README 和当前媒体配置作为增量参考快照加入会话，未变化时不重复发送；权限、AGENTS.md 和 Skill 指令继续按原有规则及时生效。
- 上下文用量明细新增请求前缀变化诊断，区分模型、工具、系统提示、参数、历史变化及仅追加历史。诊断只保存摘要，不额外保存提示正文、端点或密钥；实际缓存命中率仍以服务商返回的用量为准。
- 编辑历史消息后在原会话继续，保留编辑点之前的真实模型历史，排除其后的旧上下文；显式分叉同样保留原始模型消息和工具记录。历史分支持久化，重启恢复不会重新引入已移除的消息。
- 包含尚未正式发布的 0.1.12 更新：待发送任务队列及编辑、删除、立即发送，项目拖动排序，定时任务入口整理，以及子 Agent 委派和父任务中止行为优化。

## 安装与更新

- Windows x64：`Pi-Wm-0.1.13-Setup-x64.exe`；已配置更新源的客户端可通过「设置 > 关于与更新」检查、下载并确认安装。

- 本次从正式版 0.1.11 升级；0.1.12 保留为未发布草稿，不覆盖其标签或附件。

## 验证边界与限制

- 请求前缀诊断不等于服务商缓存状态，不保证缓存命中率提升；没有进行真实收费模型的性能或命中率基准测试。
- 编辑和分叉只改变会话上下文，不回滚已经发生的文件修改、命令或外部提交；重试前仍需核对外部状态。
- 旧版仅复制显示内容的分叉会话若缺少原始模型历史，会拒绝编辑或再次分叉，请回到原会话操作。
- 项目排序保存在当前客户端，不跨设备同步；委派约束属于模型提示策略，不是新增的工具 API 授权边界。
- Windows 安装包未签名；macOS 使用 ad-hoc 签名、未经公证，系统可能提示未知发布者或拦截安装。
