# Pi-Wm v0.1.15

## 本次更新

- 优化 Agent Teams 成员与任务卡片、状态指示、进度条和任务统计；补充详情关闭按钮、ESC 关闭与小屏布局。修复键盘监听位置错误及颜色默认值问题。
- 历史消息编辑在原模型历史中定位并回退，避免每次编辑创建独立历史；补充持久化回退标记，防止重开、重试时恢复已被替换的消息。历史编辑不撤销文件操作或其他外部效果。
- 优化默认系统提示中的任务授权、中途消息、故障恢复、验证与进度沟通规则；提供实际工作目录、Shell、后端与网络能力，避免混淆本地环境和 Docker。
- 电脑操作、媒体生成和技能提示按当前会话实际可用工具生成；工具缺失时明确限制，不引导绕过权限或重复提交收费生成任务。

## 安装与更新

- Windows x64：`Pi-Wm-0.1.15-Setup-x64.exe`。已配置更新源的客户端可在“设置 > 关于与更新”检查、下载并确认安装。
- Mac Apple Silicon：`Pi-Wm-0.1.15-mac-arm64.dmg`；Intel：`Pi-Wm-0.1.15-mac-x64.dmg`。Mac 仍需手动替换应用；ZIP 为另一种分发格式。
- 不包含本地会话数据库、预览脚本、备份文件、凭据或测试专用更新元数据。
