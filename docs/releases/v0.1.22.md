# Pi-Wm v0.1.22：DeepSeek 账号接入与登录确认优化

截至 2026-10-16，本版已完成本地 Windows 发布候选构建与定向验证，正在准备 GitHub 发布。macOS 附件须通过本版独立构建与验证后上传；所有附件核验完成前保持草稿，不将历史版本的构建结果视为本版验证。

## 本次更新

- 官方账号页面新增 DeepSeek 开放平台账号浏览器授权，无需手动填写 API Key。调用消耗平台余额，不是免费网页版聊天额度；实际账号授权、模型权限和计费仍待实测。
- DeepSeek 首版接入固定模型目录 `deepseek-flash`、`deepseek-v4-pro`，支持文本、工具调用和 off/low/high/max 思考。授权使用 PKCE 与随机 state，临时回调仅监听本机回环地址；取消、超时或结束后关闭监听，拒绝迟到令牌。
- DeepSeek 凭据保存在现有加密账号文件，模型请求限定官方推理地址并拒绝重定向；补充错误脱敏。退出先删除本地凭据，再尽力执行远端退出。
- Claude、ChatGPT、Grok 登录前增加对应风险确认；取消或 Escape 不发起授权。ChatGPT 浏览器和设备码方式均需每次确认。风险等级是第三方定性提示，并非服务商官方评级或封禁概率。
- DeepSeek 登录前明确提示平台余额计费和第三方接入限制。
- 用量统计范围改用带图标、选中标记的下拉菜单，支持方向键、Home/End、Enter、Escape、Tab 与点击外部关闭；保留全部历史用量统计逻辑。

## 已知限制与发布前待办

- DeepSeek 尚未验证真实账号授权、余额扣费或实际模型可用性；未接动态模型目录、图片/Files 或余额查询。价格未知暂按零值记录，**费用统计不代表免费或真实账单**。授权失效需退出后重新登录，不提供自动刷新流程。
- 登录确认不保证账号安全或服务商允许第三方使用，服务商可能撤销授权、限流或限制账号。
- 本版未配置 Windows 发布者签名；不要将构建日志中的 signing 步骤视为已完成发布者签名。
- 按改动风险执行定向检查，未运行全仓库测试、完整 E2E、完整桌面测试、真实安装升级矩阵或收费模型请求。安装器、更新器和依赖未发生修改。
- macOS Apple Silicon/Intel 尚需独立 CI 构建、归档与包内启动验证；未生成或上传本版 Mac 附件。
- 保留既有前端主包超过 500 kB、SQLite 实验性和构建依赖弃用提示。
- 正式发布前需确认源码提交与标签、完成所需平台构建，将同次构建的附件上传草稿并核验后再公开发布；发布后再检查公开更新源。公开发布状态与远端验证结果在完成后补充记录。
