# Pi-Wm v0.1.23：Grok 生图与媒体模型配置优化

发布候选：Windows x64 构建与定向验证已通过；macOS Apple Silicon / Intel 构建、附件核验与正式发布将在完成后记录。

## 本次更新

- 新增 Grok Images 协议，支持同步文生图和单张参考图编辑。自动识别 xAI 官方地址；原生 Grok 中转可手动选择协议，OpenAI 格式中转仍沿用 OpenAI Images。
- 生图服务提供「自动识别 / OpenAI Images / Grok Images」选项，已添加模型可分别保存协议；同一服务支持不同模型使用不同协议，修改协议不改变默认模型，重启后保留。
- 模型发现新增 Grok 图片系列识别，避免将普通聊天模型误分类为生图模型。
- Grok 支持画面比例和 1k / 2k 分辨率，质量参数按模型限制；不支持的显式参数在提交前报错，不静默忽略。旧 grok-2-image 不启用新版尺寸与参考图能力。
- Grok 参考图使用 JSON + Base64，OpenAI 保持 multipart；参考图仅允许当前工作区可访问的图片，增加大小与格式检查。
- 媒体状态提供 imageCapabilities，帮助 Agent 使用正确参数；扩展原有结果恢复机制，下载失败不自动切换协议或重复提交收费请求。
- 优化手动添加图片／视频服务入口：卡片式按钮、类型图标、展开状态与键盘焦点样式。
- 补充协议配置、结果恢复和媒体 Skill 回归；修正测试对宿主参考快照的读取，保留配置存在、密钥隐藏与实际生成断言。

## 下载与安装

- Windows x64：下载 `Pi-Wm-0.1.23-Setup-x64.exe`，或在已配置更新源的客户端通过「设置 > 关于与更新」升级。
- macOS Apple Silicon：选择 `Pi-Wm-0.1.23-mac-arm64.dmg`；Intel：选择 `Pi-Wm-0.1.23-mac-x64.dmg`。以 Release 实际附件为准，也提供 ZIP 与 SHA-256 文件。Mac 手动替换应用，不提供自动更新。
- 发布附件不包含本地会话、预览数据或凭据。
