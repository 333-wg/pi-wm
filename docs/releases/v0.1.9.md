# Pi-Wm v0.1.9

## 本次更新

- Windows 新增系统托盘：关闭窗口后隐藏到托盘并保持后台服务运行；单击、双击或菜单可恢复窗口，托盘菜单可彻底退出。主动退出和更新安装不受隐藏行为阻碍。
- MCP 支持全局与工作区两种配置范围。全局服务可跨工作区复用，同名工作区配置优先；支持显式迁移范围，迁移后需重新授权。
- 视频生成新增国内原生协议：豆包 / Seedance、即梦、可灵、通义万相、MiniMax / 海螺、Vidu；新增 Google Veo、Google Gemini Omni 与 Grok 原生协议。
- 视频设置增加对应预设和双凭据输入，完善参数校验、异步任务查询、任务恢复和安全下载；不确定的提交结果不会自动重投付费任务。
- 团队协作强化持续分派、成员复用、按需补充成员，以及完成或失败后的目标核对。该改动属于模型协作策略，不代表模型一定执行所有分派要求。

## 安装与更新

- Windows x64 使用 `Pi-Wm-0.1.9-Setup-x64.exe`。
- Mac Apple Silicon 使用 `Pi-Wm-0.1.9-mac-arm64.dmg`，Intel 使用 `Pi-Wm-0.1.9-mac-x64.dmg`。
- Mac ZIP 为另一种分发格式，无需与 DMG 同时下载。

## 验证边界与限制

- 视频协议测试使用本地模拟响应；尚未使用真实付费账号逐一验证供应商出片，不保证账号权限、地区、配额或模型可用性。
- 原生视频协议主要覆盖文生视频和单张参考图；具体参数及未开放能力见 `docs/native-video-adapters.md` 和 `docs/international-video-adapters.md`。
- Windows 安装包未进行代码签名；macOS 为 ad-hoc 签名，未公证，系统可能提示安全警告。
- Windows 系统托盘为本次新增；不宣称 Mac 同时具备托盘功能。
- 真实安装升级验收与单元测试、包内容检查分开记录，不以模拟安装器测试代替真实安装验收。
