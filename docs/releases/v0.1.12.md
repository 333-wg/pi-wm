# Pi-Wm v0.1.12

## 本次更新

- 新增可管理的待发送任务队列：任务执行中发送的补充内容默认排队，在当前任务结束后依次执行；可编辑、删除或选择「立即发送（打断）」。排队消息开始执行时才进入聊天记录。
- 队列支持持久化和多窗口同步；并发编辑时保留本地草稿并要求确认覆盖，发送回执不会清空新输入，已删除的待执行任务不会在恢复时重新进入模型上下文。
- 项目侧栏支持拖动排序，也可通过项目菜单上移、下移；排序保存在当前客户端，不改变选中项目。保存失败时明确提示。
- 精简定时任务入口，移除顶部工作台重复标签，保留侧栏定时任务中心。
- 调整子 Agent 委派策略：普通任务默认在主对话执行，用户明确要求时才委派；明确同步子任务会等待返回。父任务中止时请求取消子任务并及时解除等待，不再等待子任务工作进程结束。

## 安装与更新

- Windows x64：`Pi-Wm-0.1.12-Setup-x64.exe`；已配置更新源的客户端可通过「设置 > 关于与更新」检查、下载并确认安装。
- Mac Apple Silicon：`Pi-Wm-0.1.12-mac-arm64.dmg`；Intel：`Pi-Wm-0.1.12-mac-x64.dmg`。ZIP 为另一种分发格式；Mac 仍需手动替换应用。

## 验证边界与限制

- 项目排序保存在当前客户端的本地存储，不跨设备同步；清理本地存储会清除排序偏好。
- 「立即发送（打断）」会中止当前任务并优先处理所选消息，其他待发送消息继续排队。
- 委派约束属于模型提示策略，不是新增的工具 API 授权边界，也不保证模型始终遵循。
- Windows 安装包未签名；macOS 使用 ad-hoc 签名、未经公证，系统可能提示未知发布者或拦截安装。
